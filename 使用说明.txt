English Quick Check v0.2.1 · Windows x64 便携版

1. 解压整个文件夹后，双击 English Quick Check.exe。
   不需要安装 Python。不要把 exe 单独移出文件夹；_internal 是必需运行文件。
2. 默认本地检查不联网。“设置” → “API 与用量”填入自己的 Key 后，可主动使用 AI。
3. 默认在聊天输入框按 Ctrl+Alt+G 可读取整个输入框并显示悬浮建议。
   “设置 → 常规”可修改快捷键，保存后立即生效、下次启动沿用；占用时保留原快捷键。
   支持 Ctrl / Alt / Shift 加字母、数字或 F1–F24，至少包含 Ctrl 或 Alt。
   默认只做本地检查；主动勾选快捷键 AI 开关才会上传原文。此开关会保存。
4. AI 检测到中文 / 中英混合时，默认将整句转成完整英文并用中文解释。
   设置中可改为保留中文、只检查英文。本地规则不能翻译。AI 可能误译，请核对。
5. 不自动替换、不自动发送。建议阅读解释后自己修改英语句子。
6. 主窗口关闭默认进入系统托盘；设置中可改为直接退出。
   托盘图标可能位于任务栏右侧“^”中，双击打开主窗口，右键 → 退出彻底关闭。
   主窗口右上角“退出软件”也可退出。“后台运行”进入托盘；普通最小化保留任务栏入口。
   悬浮窗 × 仅隐藏。托盘不可用时关闭主窗口会退出，避免找不到入口。
7. 设置可选择下次启动直接进入托盘、中文处理、快捷键 AI、富文本剪贴板覆盖、API 和调用上限。
   默认不上传、不覆盖富文本；主动更改会保存。没有开机自启。
8. 设置与数字用量保存在 %LOCALAPPDATA%\EnglishQuickCheck，不在便携文件夹中。
   API Key 使用当前 Windows 用户 DPAPI 加密。发布包不包含你的 Key。
   删除便携文件夹不会删除这些数据；需要时可自行删除该用户数据目录。
9. 捕获会模拟 Ctrl+A/C；先确认焦点在输入框。富文本剪贴板默认受到保护。
10. 此版本未签名，Windows SmartScreen 可能提示未知发布者。
    仅从可信来源下载，核对发布页 SHA256。不要关闭安全软件。

更新时先完全退出旧版再启动新版，避免重复运行和快捷键冲突。
AI 可能误判；本地规则不是完整语法检查器。详细功能、限制、隐私说明见 README.md。
